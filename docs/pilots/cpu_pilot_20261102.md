## Execution and interpretation

Source revision: `9fbbbc8` (clean checkout during training and collection). Qiskit 2.1.2 / Aer 0.17.2 on the local macOS CPU. Two model initializations, one fixed Breast Cancer split, 40 training samples, depth-one two-qubit QDTs, two repetitions, and six execution conditions. The test set was not evaluated.

All 24 runs completed without failed attempts. A second campaign invocation skipped all 24 verified outputs without execution. Exact native batching and packing preserved predictions in this pilot. Most of the observed gain over one-circuit requests is already available through native request batching; these observations do not establish a distinct advantage for spatial packing. Finite-shot quality variation is stochastic and is not evidence that larger packing improves predictions.

The figure was visually inspected. Matplotlib's system-font discovery stalled on this Mac; its process was stopped without affecting saved experiments, and plotting was rerun with `MPL_IGNORE_SYSTEM_FONTS=1` and a writable temporary `MPLCONFIGDIR`, using bundled fonts. Simulation results were not rerun for this plotting issue.

Raw models, plans, attempts, counts, and PDF/PNG figures remain under `results/cpu-pilot/` and are ignored by Git. This committed report and JSON summary preserve the main observations and artifact checksums; include the raw directory explicitly in a later publication archive. Reproduction commands are in `docs/experiment_guide.md`.

This is a pipeline smoke test, not a GPU/HPC scaling study or a hardware result. Two paired models provide very limited inferential evidence, and the fixed execution order cannot exclude temporal timing effects. Larger randomized campaigns, independent calibration windows, and actual GPU/QPU validation remain required.
